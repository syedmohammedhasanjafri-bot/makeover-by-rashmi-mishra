# Makeover by Rashmi Mishra

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fsyedmohammedhasanjafri-bot%2Fmakeover-by-rashmi-mishra)

A bespoke, Awwwards-caliber luxury Bridal Lookbook & Academy Admissions Flagship Portal for **Makeover by Rashmi Mishra** (Celebrity Makeup Artist & Academy Founder, Kurla, Mumbai — 10.1K Community).

Benchmarked against Charlotte Tilbury × The Row editorial aesthetic (100% Daylight Luxury).

---

## 💎 Architectural Highlights

- **Framework:** Next.js 15 (App Router, Server Components, Turbopack)
- **Styling:** Tailwind CSS with bespoke daylight tokens:
  - Mulmul Ivory (`#FDFBF7`)
  - Rosewater Alabaster (`#FBF8F5`)
  - Warm Travertine (`#F5EFEB`)
  - Deep Charcoal Ink (`#1C1917`)
- **Geometry:** Razor-sharp 90-degree corners (`rounded-none`).
- **Smooth Inertia:** Lenis smooth scrolling (`@studio-freight/lenis` / `lenis`).
- **Dynamic WhatsApp Concierge:** Pre-formatted, encrypted booking dockets routed to verified `https://wa.link/grbesm`.
- **Compliance:** 100% compliant with India's **Digital Personal Data Protection (DPDP) Act 2023**.

---

## 🏛️ Dual Persona Business Architecture

1. **The Discerning Luxury Bride:**
   - Filterable high-definition Lookbook: *Traditional Bridal*, *Engagement Glam*, *Reception Dewy*, *Maharashtrian Regal*.
   - Shimmering travertine skeleton loaders with zero layout shift (CLS).
   - 1-Tap *"Check Date Availability"* WhatsApp modal.
2. **The Aspiring Artistry & Nail Tech Student:**
   - **Course 1:** 30-Day Masterclass: Basic to International Bridal Makeup & Hairstyle Diploma (80% practical hands-on training on live models, 8 bridal drapes, airbrush protocols).
   - **Course 2:** Professional Nail Art & Extension Diploma (10-day intensive covering dual forms, acrylic sculpting, Russian cuticle prep, 3D floral art).
   - **Upcoming Batches:** November 2026 & December 2026 Cohorts.
   - Interactive *"Download Course Syllabus & Fee Structure"* inquiry modal.

## 🚀 Quick Start & Development

```bash
# Clone the repository
git clone https://github.com/syedmohammedhasanjafri-bot/makeover-by-rashmi-mishra.git
cd makeover-by-rashmi-mishra

# Install dependencies
npm install

# Run architectural audit
npm run verify

# Start development server
npm run dev

# Run production build
npm run build
```
